本版本重点完善了双系统离线交付、网络安全边界、断点续跑、自动发现，以及基于真实 XPU/NIC 拓扑的 RDMA 与 XCCL 验收能力。

## 主要更新

### 交付与下载器

- 当前正式交付 profile 收敛为 `ubuntu22.04-x86_64` 和 `kylin10sp3-x86_64`，移除 CentOS 7 交付 profile。
- 下载器支持交互选择或通过 `--profile` 指定系统，只下载对应 profile 的物料。
- 下载器自动校验、解包并合并 base/profile 包，同时生成所选系统的 `planning/bundle.json`。
- Linux、macOS 和 Windows 使用独立的归档文件属性处理逻辑；Linux/macOS 保留可执行权限。
- COS release 默认只保留最近两个版本，降低重复物料的存储成本。
- Bundle 样例拆分为 Ubuntu 22.04 和 Kylin V10 SP3 两份，物料路径统一采用 `data/...`。

### apply 初始化

- 增加全流程断点续跑：默认 apply 会在 `/var/lib/envinit/apply-progress.json` 记录成功 stage，失败或重启后从未完成位置继续；可通过 `--restart` 主动从头执行。
- 重新梳理网卡自动发现和绑定逻辑。优先按 MAC 精确匹配；没有 MAC 时根据物理设备、速率、驱动、PCI 和链路状态生成候选，并通过 TUI 做最终确认。
- `configure_management_network=false` 时不再发现、备份、重命名、改写或持久化管理网配置，只处理 RDMA 网络。
- 管理网和 RDMA udev 规则拆分保存，接口确认结果统一写入 `/var/lib/envinit/selected_interfaces`；旧 RDMA 路径保留兼容软链接。
- Kylin 自动选择 NetworkManager 或 legacy network，Ubuntu 使用 netplan/networkd，并补充相应的路由重放机制。
- OFED 前置依赖改为工具内置检查和安装。
- ACSCtl、MaxReadReq、网卡 ring buffer、RoCE adaptive routing 和 CNP DSCP 48 固化到 post boot 服务，并在当次 post stage 立即生效。

### discover 自动发现

- 新增 `discover` 子命令，通过 SSH 读取管理网、RDMA IP、GID、PCI 和接口状态。
- 支持交互 review、`--yes` 自动接受和 `--dry-run` 只读验证。
- 支持没有 MAC 的项目，由现场在 review 中明确管理网及 `rdma1..rdmaN` 的逻辑顺序，再写回 inventory。
- 管理网和 RDMA 候选互斥，避免把 400G RDMA 地址误写为管理 IP。

### check 与 RDMA 带宽

- check 配置按 `bandwidth`、`rdma_ping`、`ssh`、`xccl` 分层组织，同时兼容旧版平铺字段。
- XDR mmap 带宽测试运行前读取真实 `xpu-smi topo -m`，动态解析 XPU、网卡和 `mlx5_N` 的映射，不再依赖固定 `rdma_groups`。
- 每个 XPU 只测试最近的合理网卡路径，优先级为 `PIX -> PXB -> PHB -> NODE -> SYS`，避免生成无实际业务意义的跨 PCIe 慢链路组合。
- 当无法使用 PIX、只能退化到更远拓扑时，命令输出和汇总结果会明确显示 `WARN`、`DEGRADED` 及 PCIe/NUMA 限速提示。
- dry-run 会执行只读 topo/sysfs 发现并输出真实测试命令，不启动流量。
- RDMA ping、NIC/IB 计数器、带宽和拓扑告警统一汇总到最终退出状态。

### XCCL 集合通信验收

- check 集成宿主机原生 XCCL perf，不依赖容器，也不要求现场编译 MPI。
- 使用随 profile 交付的预编译 MPICH 5.0.1 runtime 和 XCCL 3.2.2.0 原始包。
- 支持单机 smoke test 和多机集合通信测试；单机模式使用本地 Hydra launcher，不创建临时 SSH 密钥。
- 多机模式自动生成临时 SSH 密钥、分发运行时和 rank wrapper，完成后清理远端文件及授权记录。
- 根据每台机器的真实 XPU/NIC 拓扑生成 `BKCL_FORCE_RDMA_NICS_ORDER`、`BKCL_RDMA_NICS` 等环境变量，并检查 XPU 数量、接口顺序、动态库依赖和管理接口一致性。
- 汇总 XCCL 算法带宽、bus bandwidth、拓扑状态和门槛判定；非 PIX 映射会给出明确退化提示。

## 兼容性与注意事项

- CentOS 7 不再属于正式交付范围。
- `data/...` 路径相对执行 `env_init` 命令时的当前工作目录，现场应先进入 `env_tool/` 再执行命令。
- 已经通过带内管理网接入的机器，建议保持 `configure_management_network=false`；确需配置时建议设置 `apply_network_immediately=false`。
- 新版 bundle 可省略 `rdma_groups`，XDR 和 XCCL 都会从 inventory、sysfs 与 `xpu-smi topo -m` 动态生成映射。
