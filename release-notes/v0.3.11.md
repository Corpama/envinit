本版本为 downloader 增加整个 profile 的聚合下载进度、图形化进度条和实时下载速度，方便交付人员判断数 GB 离线物料的下载状态。

## 主要更新

- profile 物料下载显示总百分比、固定宽度进度条、已完成/总容量、实时平均网络速度，以及已处理/总文件数。
- 六个并发 worker 共用同一套聚合统计，不再为每个小文件分别输出进度，避免 1000 多个文件造成终端刷屏。
- 已校验完成的文件和已有 `.part` 断点会计入总完成进度，但不会计入本轮网络速度，避免续跑时显示虚假的超高下载速度。
- 服务端不支持 Range、要求从头下载时会先扣除已有断点容量，再按实际重新下载字节更新进度，保证百分比不重复累计。
- 交互终端在同一行动态刷新；重定向到日志或测试输出时只保留起始和最终状态。
- 零字节悬空 COS/AList 条目被跳过时，进度行会让位给完整 WARNING，随后继续刷新，不会覆盖告警内容。

## 显示样例

```text
Material [===========                   ]  37.42%  2.67 GiB/7.14 GiB  183.60 MiB/s  641/1529 files
```

## 升级说明

- 继续使用原来的输出目录即可，已经完成的文件、`.part` 断点和校验标记都会复用。
- 本次只更新 downloader，不重新读取、打包或上传 profile 大物料。
