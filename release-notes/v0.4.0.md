# v0.4.0

本版把下载交付和装机规划分开：用 downloader 组装指定系统的交付目录，再用 `env_init config` 离线准备或编辑规划表。

## 配置与兼容性

- 在 inventory 编辑器选中机器行后，按 `d` 或 `Delete` 可删除该行。在初始化区修改管理网模式、目标名、前缀或网关，会同步已有机器。单口模式的 `mgmt_iface1` 跟随目标名；bond 改名保留物理成员网卡。
- 普通规划表无需填写 `rdmaN_table` 和 `rdmaN_route_cidr`：路由表从槽位 1 的 101 起依次编号，直连网段由该槽位的 IP 和前缀计算。旧表显式指定的值仍可读取。
- 更新 Ubuntu 22.04、Kylin V10 SP3 的 bundle 和公共 inventory 样例。升级时使用新的 `--output-dir`，再导入旧规划；同版本、同 profile 续传时保留已有规划。

## 网络执行与检查

- `apply` 增加网络改配事务、拓扑核验、SSH 网络 worker、阶段重跑和 sysctl 配置归属记录。RDMA 网关辅助探测默认开启，可用 `defaults.rdma_gateway_probe.enabled: false` 关闭。
- 完善 RDMA 发现、GID 选择、XCCL 检查及结果报告。自定义 SSH 端口可通过 `check.ssh.port` 统一用于 SSH 和 SCP。

## 验证与交付

- 发布前通过 Go 全量测试、`go vet`、示例 JSON 与发布脚本语法检查；Linux 两种架构的 `env_init` 及 Linux/macOS/Windows 各两种架构的 downloader 已通过试编译。维护者已确认相关功能经过实验环境验收。
- GitHub 提供 downloader、`manifest.json` 和 `SHA256SUMS`。从本版下载后，可先在交付目录运行 `./env_init config --check-only` 检查模板。COS 按默认策略保留最新两个版本。
