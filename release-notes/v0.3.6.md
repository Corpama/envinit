本版本正式提供 Ubuntu 22.04 与 Kylin V10 SP3 双 profile 离线交付，并完善网络初始化、自动发现、断点续跑、RDMA 带宽检查和 XCCL 集合通信验收。

## 主要更新

### 交付与下载器

- 下载器支持交互选择或使用 `--profile` 指定 Ubuntu/Kylin，只拉取对应物料。
- 自动校验、解包并合并 base/profile 包，同时生成对应的 `planning/bundle.json`。
- Linux、macOS 和 Windows 使用独立的归档属性处理逻辑。
- 发布流程按父目录、版本目录、profile 目录刷新 AList，并在创建 Release 前逐个验证所有下载地址。

### apply 初始化

- 增加全流程断点续跑，失败或重启后从未完成 stage 继续；`--restart` 可主动从头执行。
- 没有 MAC 时可根据速率、驱动、PCI 和链路状态自动生成网卡候选，并通过 NIC Binding Review 确认。
- `configure_management_network=false` 时不会发现、备份、重命名、改写或持久化管理网配置。
- 管理网和 RDMA udev 规则分别保存，接口确认结果统一写入 `/var/lib/envinit/selected_interfaces`。
- 内置 OFED 前置依赖检查，并固化 ACSCtl、MaxReadReq、ring buffer、RoCE adaptive routing 和 CNP DSCP 48 等重启后调优。

### discover、RDMA 与 XCCL 检查

- 新增 `discover`，支持交互确认、`--yes` 和 `--dry-run`。
- check 配置按 `bandwidth`、`rdma_ping`、`ssh`、`xccl` 分层，同时兼容旧字段。
- XDR 根据 inventory、sysfs 和 `xpu-smi topo -m` 动态生成 XPU/NIC 映射，不再依赖固定 `rdma_groups`。
- 非 PIX 映射会明确标记 `WARN`、`DEGRADED` 以及 PCIe/NUMA 限速提示。
- 集成宿主机原生 XCCL perf，使用预编译 MPICH 5.0.1 与 XCCL 3.2.2.0，支持单机和多机模式。
- 多机模式自动管理临时 SSH 密钥、运行时分发、rank 环境变量和远端清理。

## 使用注意事项

- `data/...` 相对执行命令时的当前目录，现场应先进入 `env_tool/`。
- 带内管理环境建议保持 `configure_management_network=false`。
- `rdma_groups` 可以省略，XDR 和 XCCL 会从真实拓扑动态生成映射。
