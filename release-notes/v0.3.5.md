本版本完善了 Ubuntu 22.04 与 Kylin V10 SP3 双 profile 离线交付，并重点增强网络初始化、自动发现、断点续跑、RDMA 带宽检查和 XCCL 集合通信验收。

## 主要更新

### 交付与下载器

- 正式提供 `ubuntu22.04-x86_64` 和 `kylin10sp3-x86_64` 两套独立 profile。
- 下载器支持交互选择或使用 `--profile` 指定系统，只拉取对应物料。
- 下载完成后自动校验、解包并合并 base/profile 包，同时生成对应的 `planning/bundle.json`。
- Linux、macOS 和 Windows 分别处理归档文件属性，Linux/macOS 会保留可执行权限。
- Bundle 物料路径统一使用 `data/...`，Ubuntu 与 Kylin 提供独立样例。

### apply 初始化

- 增加默认全流程断点续跑，失败或重启后可从未完成 stage 继续；`--restart` 可主动从头执行。
- 完善物理网卡自动发现与 NIC Binding Review，没有 MAC 时也可根据速率、驱动、PCI、链路状态生成候选并人工确认。
- `configure_management_network=false` 时不会发现、备份、重命名、改写或持久化管理网配置，只处理 RDMA 网络。
- 管理网和 RDMA udev 规则分别保存，接口确认结果统一写入 `/var/lib/envinit/selected_interfaces`。
- 内置 OFED 前置依赖检查，并固化 ACSCtl、MaxReadReq、ring buffer、RoCE adaptive routing 和 CNP DSCP 48 等重启后调优。

### discover 与 check

- 新增 `discover`，通过 SSH 发现管理网和 RDMA 接口，支持交互确认、`--yes` 和 `--dry-run`。
- check 配置按 `bandwidth`、`rdma_ping`、`ssh`、`xccl` 分层，同时兼容旧版字段。
- XDR mmap 带宽测试根据 `xpu-smi topo -m`、inventory 和 sysfs 动态生成 XPU/NIC 映射，不再依赖固定 `rdma_groups`。
- 每个 XPU 优先选择 PIX 网卡；只能使用 PXB、PHB、NODE 或 SYS 时，结果会明确标记 `WARN`、`DEGRADED` 和 PCIe/NUMA 限速提示。
- dry-run 会完成只读 topo/sysfs 发现并输出真实测试命令，不启动流量。

### XCCL 集合通信验收

- 集成宿主机原生 XCCL perf，使用 profile 内预编译 MPICH 5.0.1 与 XCCL 3.2.2.0，不依赖容器或现场编译 MPI。
- 支持单机 smoke test 和多机集合通信测试。
- 多机模式自动管理临时 SSH 密钥、运行时分发、rank wrapper 和远端清理。
- 根据每台机器的真实拓扑注入 XCCL/XPU 环境变量，并检查 XPU 数量、网卡顺序和动态库依赖。
- 汇总算法带宽、bus bandwidth、拓扑状态和门槛判定，非 PIX 映射会给出明确退化提示。

## 使用注意事项

- `data/...` 相对执行命令时的当前目录，现场应先进入 `env_tool/` 再运行工具。
- 带内管理环境建议保持 `configure_management_network=false`；确需配置管理网时建议设置 `apply_network_immediately=false`。
- `rdma_groups` 可以省略，XDR 和 XCCL 会从真实拓扑动态生成映射。
